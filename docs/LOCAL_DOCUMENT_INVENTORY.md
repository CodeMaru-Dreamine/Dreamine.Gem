# 로컬 SEMI 관련 문서 인벤토리

조사일: 2026-08-10  
조사 범위: `D:\SEMI\SEMI_DOC`의 모든 하위 폴더(읽기 전용)

이 문서는 구현 근거를 선별하기 위한 인벤토리다. 원문, 고객사명, 내부 식별자,
상세 사양 및 원본 경로는 저장소에 기록하지 않는다. `고객사 Engineering Guide`,
`고객사 Online/Compliance Test Specification`, `사내 교육자료·발표자료`, `기타
참고자료`는 구현 아이디어를 보조할 뿐 Normative 근거가 아니다.

## 조사 방법과 제한

- 전체 파일 60개 중 문서 58개를 조사했다. 형식은 PDF 49, DOC 4, PPT 3,
  PPTX 1, HWP 1이며 나머지 2개는 문서가 아닌 데이터베이스 보조 파일이다.
- 모든 파일에 SHA-256을 계산했다. PDF는 속성·페이지 수와 가능한 경우 표지,
  목차 및 전체 페이지 키워드 색인을 확인했다.
- 암호화된 공식 표준은 복사 제한을 우회하지 않고 렌더링한 표지·목차만 확인했다.
- Word와 PowerPoint는 원본을 읽기 전용으로 열어 익명 임시 PDF 또는 슬라이드
  텍스트로 확인했다. HWP 파일은 HWP 3.0 헤더와 제목까지만 확인했으며 설치된
  판독기가 없어 본문/페이지 수는 확인하지 못했다.
- 문서 원문이나 임시 변환물은 저장소에 포함하지 않는다.

## 중복 판정

- D01: L001과 L030은 SHA-256이 같은 정확 중복이며 문서 Revision도 동일하다.
- D02: L046과 L049는 SHA-256이 같은 정확 중복이며 문서 Revision도 동일하다.
- D03: L036과 L058은 SHA-256이 같은 정확 중복이며 문서 Revision도 동일하다.
- L035/L036/L058은 동일 계열의 DOC/PDF 자료다. L036/L058만 바이트 단위 정확
  중복이며 L035는 형식이 달라 정확 중복으로 계산하지 않았다.
- L050/L055는 내용이 유사하지만 SHA-256이 달라 별도 자료로 유지했다.

따라서 정확 중복은 3개 그룹, 6개 파일이다. 구현·테스트 근거에는 각 그룹의 한
사본만 참고한다.

## 로컬 조사 결론

로컬 자료만으로 확인 가능한 GEM 기준 Revision은 E30-0611이다. GEM300 직접 후보는
E39-0703(Reapproved 1109), E40-0312, E87-0312, E90-0312, E94-0314다.
E37.1 및 E116 계열은 참조 흔적만 있고 공식 원문이 없으므로, 최신 Revision과 구매
가능 여부를 SEMI 공식 웹 자료에서 확인한 뒤 구현 범위와 추적표의 제한을 확정한다.
