# Security policy

Report vulnerabilities privately to repository maintainers. Never attach credentials, customer identifiers, proprietary captures, or licensed standards documents.

Validate and authorize remote commands at the application boundary. Registered handlers receive read-only parameter snapshots, but handlers remain responsible for domain authorization and side effects. Bound process-program and spool sizes at the surrounding application layer, protect the underlying HSMS network, and avoid logging sensitive parameter/program bodies.

Supported fixes target the latest source revision; publication and servicing status are tracked separately from source readiness.
